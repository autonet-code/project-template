# Submissions

Deliverables and evidence for this project. If the work is disputed, the arbiter reviews this folder together with `TERMS.md`.

## What to put here
- **Work products**: code, designs, reports and other deliverables.
- **Milestone evidence**: progress reports, screenshots, demo videos.
- **Agreed changes**: any change to scope or terms both sides agreed to, with the record of that agreement.
- **Communication**: messages or meeting notes that matter to how the work was agreed or delivered.
- **Dispute material**: claims, responses and supporting evidence.

## Conventions
- Name files by what they contain, e.g. `milestone-1-report.pdf`, `scope-change-2026-03-15.md`.
- Prefer PDF or Markdown for documents and PNG or JPEG for images. GitHub rejects files over 100 MB.
- Keep it current through the project, not only when a dispute starts.
