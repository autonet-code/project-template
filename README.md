# Project Template

Start a new project in a jurisdiction's economy from this repository. Click **Use this template**, fill in `TERMS.md`, and link your copy when you create the project in the Projects tab.

## What's here
- **TERMS.md**: the agreement between the author, the contractor and the backers: scope, deliverables, payment, deadlines and how disputes are handled. Its hash is recorded on chain when the project is created, so finish it before you create the project.
- **submissions/**: deliverables and evidence. If there is a dispute, the arbiter decides from `TERMS.md` and what is in this folder.

## How a project runs
1. **Create**: the author copies this template, writes `TERMS.md` and creates the project, naming the contractor and the arbiter.
2. **Fund**: backers add funds to the project's escrow.
3. **Sign**: the contractor signs and stakes, accepting the terms.
4. **Deliver**: the contractor puts the work in `submissions/`.
5. **Release or dispute**: backers vote to release the funds to the contractor or to dispute. A dispute goes to the arbiter, whose ruling can be appealed to the jurisdiction's governance.

## For authors
- Be specific in `TERMS.md`: what counts as done, by when, and how payment is split.
- Name an arbiter both sides trust.

## For contractors
- Read `TERMS.md` before you sign; signing commits your stake to these terms.
- Keep `submissions/` current, since it is your evidence if the work is disputed.
